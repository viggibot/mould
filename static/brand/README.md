# Akritio — brand assets

Mark 1b (two-part mould: two halves, parting line, cast part).

## Files
- `akritio-logo-horizontal.svg` — primary lockup (light backgrounds)
- `akritio-logo-horizontal-dark.svg` — primary lockup (dark backgrounds)
- `akritio-logo-stacked.svg` — centered/stacked lockup
- `akritio-logo-horizontal.png` — raster lockup @3x (transparent)
- `akritio-badge.svg` — app icon (amber badge + mark)
- `akritio-mark.svg` / `akritio-mark-1024.png` — mark only, transparent
- `favicon.svg` + `favicon-16/32/48/180/192/512/1024.png`
- `head-snippet.html` — paste into `<head>`
- `site.webmanifest`

## Colours
- Amber `#F5B93F`  · Ink `#17191F`  · Slate `#5B616E` / `#9AA0AB`
- Teal (mould) `#5BD6A6`  · Coral (cast part) `#F1654C`
- Indigo (CTA) `#6C5CE7`

## Type
- Wordmark: **Space Grotesk** 700 (the "i" dot is coral `#F1654C`)
- Tagline: **Space Mono**, uppercase, tracked

The lockup SVGs reference Space Grotesk + Space Mono via Google Fonts; your
site already loads them. For fully self-contained files, outline the text in
a vector editor. Icons/favicons contain no text and are portable everywhere.

## Favicon note
`favicon.svg` + the PNGs cover all modern browsers. For a legacy `.ico`,
convert `favicon-32.png` at favicon.io or realfavicongenerator.net.
